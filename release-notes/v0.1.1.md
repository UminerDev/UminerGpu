# Uminer GPU v0.1.1

## English

This release standardizes BTX pool configuration and keeps existing command lines compatible.

- Standard miner options: `-o/--pool`, `-u/--user`, `-p/--pass`, `-d/--devices`
- Accepts both `host:port` and `stratum+tcp://host:port`
- Keeps `--worker` and the legacy JSON `worker` key as compatibility aliases
- Sends the configured password in `mining.authorize`
- Rejects missing pool/user values and unsupported TLS schemes with a clear error
- BTXPOOL global endpoint is used in the packaged examples
- Development fee remains disabled by default

Quick start (replace the masked address with a complete BTX address):

```bash
./uminer --coin btx \
  -o stratum+tcp://global.btxpool.org:23333 \
  -u btx1zq7gn...7zzqd4.rig01 \
  -p x
```

Release-gate hardware and pool checks:

- RTX 4090 (`sm_89`): CUDA digest, survivor and mainnet winner vectors passed
- BTXPOOL relay path: connection, authorization, consecutive live jobs and sustained mining verified
- An accepted share was not awaited for this release because the current pool share difficulty makes that check slow

Requirements: Linux x86_64, NVIDIA driver 580 or newer, glibc 2.39 or newer.
The archive embeds CUDA code for `sm_80/86/89/90/120`; no CUDA Toolkit is required at runtime.

Known limitations: the Linux binary is built on Ubuntu 24.04 and requires glibc 2.39.
Only plain `stratum+tcp://` is supported in this release; TLS pool URLs are rejected.

## 繁體中文

本版本統一 BTX 礦池參數，同時保留舊命令相容性。

- 標準參數：`-o/--pool`、`-u/--user`、`-p/--pass`、`-d/--devices`
- 支援 `host:port` 與 `stratum+tcp://host:port`
- 保留 `--worker` 和舊 JSON `worker` 欄位作為相容別名
- `mining.authorize` 會傳送使用者設定的密碼
- 缺少礦池/使用者或傳入不支援的 TLS URL 時會明確拒絕啟動
- 套件示例使用 BTXPOOL 全球入口
- 開發費預設仍為關閉

快速啟動（必須將隱藏中間字元的地址替換為完整 BTX 地址）：

```bash
./uminer --coin btx \
  -o stratum+tcp://global.btxpool.org:23333 \
  -u btx1zq7gn...7zzqd4.rig01 \
  -p x
```

RTX 4090 已通過 CUDA digest、survivor 和主網中獎向量；BTXPOOL 轉發鏈路已完成連線、
授權、連續實時任務和持續挖礦驗收。因目前礦池 share 難度較高，本次發佈未等待 accepted share。

執行要求：Linux x86_64、NVIDIA 580 及以上驅動、glibc 2.39 及以上。
已知限制：目前只支援明文 `stratum+tcp://`，不支援 TLS 礦池 URL；Ubuntu 24.04
建置產物要求 glibc 2.39。
