# Uminer GPU v0.1.3

## 性能

- 优化 RTX 4090（Ada `sm_89`）的矩阵生成调度，减少热路径中的重复计算。
- 为 BTX 主网参数 `n=512, b=16, r=8` 增加专用 digest kernel，避免通用路径的大型临时消息缓冲。
- CUDA 13.2、450W 热稳态背靠背测试相对 v0.1.2 提升约 `0.4%`；Ampere 和通用架构路径保持不变。

## 正确性

- 主网高度 151436 的已知中奖 nonce 与 digest 逐位一致。
- 多命中测试一次返回 `5/5` 个结果，即时提交和新 job 中断行为通过。
- 保留 v0.1.2 的矿池 `nonce64_start` 扫描范围修复。

## 环境

- Ubuntu 24.04 / CUDA 13.2 / RTX 4090。
- NVIDIA 驱动 580 或更新版本。
- 已知遗留：Linux 产物仍要求 `GLIBC_2.39`。
