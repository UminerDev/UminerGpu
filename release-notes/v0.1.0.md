# Uminer GPU v0.1.0

## English

First BTX binary release of Uminer GPU.

- Unified command: `uminer --coin btx`
- Linux x86_64 NVIDIA CUDA 13 build
- Embedded code for `sm_80`, `sm_86`, `sm_89`, `sm_90` and `sm_120`
- Architecture-aware CUDA execution profiles
- Automatic scan sizing enabled by default
- Multi-GPU, pool failover, watchdog, local API and CPU share verification
- Supports driver-only systems that expose `libcuda.so.1`
- Development fee disabled by default

Release-gate hardware:

- RTX 3080 (`sm_86`): package checksum, pool connection and accepted shares verified
- RTX 4090 (`sm_89`): digest, survivor set, winning nonce and pool mining verified

Requirements:

- NVIDIA driver 580 or newer
- glibc 2.39 or newer

Known limitation: v0.1.0 is built on Ubuntu 24.04 and does not run on systems
with an older glibc, including the current HiveOS 20.04 base image.

## 繁體中文

Uminer GPU 首個 BTX 二進位發佈版本。

- 統一命令：`uminer --coin btx`
- Linux x86_64 NVIDIA CUDA 13 版本
- 內建 `sm_80/86/89/90/120` 架構程式碼
- 依 GPU 架構自動選擇 CUDA 執行配置
- 預設自動調整掃描量
- 支援多卡、礦池故障切換、watchdog、本機 API 和 CPU share 複核
- 支援僅提供 `libcuda.so.1` 的純驅動系統
- 本版本預設關閉開發費

發佈驗收已覆蓋 RTX 3080 和 RTX 4090。

執行要求：NVIDIA 580 及以上驅動、glibc 2.39 及以上。

已知限制：v0.1.0 基於 Ubuntu 24.04 建置，暫不相容 HiveOS 20.04
等較舊 glibc 系統。
